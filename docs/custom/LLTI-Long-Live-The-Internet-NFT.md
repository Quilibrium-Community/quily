# Long Live The Internet (LLTI) NFT Collection

**Long Live The Internet (LLTI)** is the NFT collection associated with Quilibrium. When someone asks "what's the NFT in Quil" or "is there a Quilibrium NFT", this is the collection they mean.

## Key facts

- **Chain today:** Ethereum.
- **Contract address:** `0xd40230d5e3a6c12bc73ce80b42be4e106460bbdb`
- **Collection on OpenSea:** https://opensea.io/collection/long-live-the-internet
- **What holding it gives you:** each holder of the Ethereum LLTI NFT gets **one NFT on the Quilibrium network** when mainnet fully launches.
- **Why it matters:** that Quilibrium-side NFT is intended to be **the first collectible living on the Quilibrium network**.

## What is not documented here

The knowledge base does not yet cover the collection's supply, mint history, artwork details, or the exact mechanism and timing of the Ethereum-to-Quilibrium claim. Do not invent these. Point users to the OpenSea page and the Quilibrium Discord announcements for current details.

## Safety note

Always check the contract address above before buying, since lookalike collections can appear on NFT marketplaces.
