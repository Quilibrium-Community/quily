# node-updates - October 18, 2026

## LaMat — 3:52 PM UTC

**Sharing logs in a bug report
**
Don't post raw logs. They contain your IPs, peer IDs, host and user names, home paths and balances. Instead run:

`qclient node log export --since 2h [--filter <shard filter hex>] [--match <text>]`

- It merges all cores (or the journal) into node.log.gz, manifest.json and SHA256SUMS.
- It shows a preview and waits for you to type yes.
- Sensitive values become tokens such as ip4#7c21a0b3. A token is consistent within one export only.
- Shard filters, frame numbers, versions and public bootstrap endpoints are kept, because maintainers need them to reproduce the problem.
- Balances are removed.
- The token map (<dir>.map.txt) is for you alone. Never share it.
- Export does not hide which prover you are: your shards and join/reward frames are on-chain.

**A useful report includes:**
- the warning line itself (it carries frame, generation, shard filter, duration and error);
- the time in UTC;
- your node version;
- an export covering the window.

Feedback on lines that are noisy, unclear or not actionable is welcome on #756.
