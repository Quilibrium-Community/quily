# Community Recap — #general

**October 7, 2026** | 12:00 AM UTC – 10:54 AM UTC

## From Cassie
- Cassie confirmed that shard splitting is **not** on hold.

## Mainnet Status & Rewards
- Community members reported the first rewards flowing to selected app shards, though amounts are small and not all nodes have received rewards yet.
- Black Swan summarized the last 24 hours: first rewards for a selected app shard were distributed, confirming certain use cases work, while other previously working app shards got blocked. Cassie is reportedly working on addressing current blockers.
- Black Swan noted that if app shards become consistently operational, it would mark a major milestone and check off items 1-3 in Cassie's mainnet-live criteria list, with only item 4 remaining for testing.
- Community members expressed hope for a mainnet launch this year, though no timeline was given.

## Node Operator Economics Discussion
- A lengthy discussion took place about miner incentives given the current low token price and only ~50k Q emitted per day.
- Sone7819 questioned what would attract miners at current prices and asked about merge mining (reusing computational work from another blockchain, like Tari does with Monero). Sup responded that merge mining is "for unserious projects" and that Quilibrium wouldn't want to be tightly bound to a parent chain.
- Otter argued that Quilibrium's ring queue mechanism and dynamic shard splitting mean fewer miners are needed when rewards are low, making it a self-balancing system. He compared early Quilibrium to early Bitcoin.
- Mr.Quil defended node operators, calling them "heroes" for supporting the network with their own money.
- Sup argued the network only needs 8 nodes to stay online, hardware requirements scale with demand, and token price will follow demand — "the problem solves itself."
- Black Swan expressed concerns about decentralization if only a few nodes run mainnet, and suggested deferring detailed economics discussion until mainnet is fully operational, with Cassie presenting her vision first.
- CarlXB shared a summary of Quilibrium's proposed dynamic fee mechanism (from a 2024 Cassie post), which accounts for stored data, computation, and proof size to prevent abuse and protect prover incentives.

## Technical Issues & Fixes
- Black Swan investigated a GitHub issue (monorepo #702) and worked on graceful node shutdown, which was fixed via PR #703.
- A fix candidate for an out-of-memory (OOM) issue was submitted as PR #704.
- VELVIL VR reported frames stopped for 7 hours and seniority pumping overnight. Black Swan explained that absence of frames doesn't mean archives are dead — they could be reconciling data after tree construction fixes, and seniority increases might reflect previously uncredited work.

## Hardware Discussion
- Sup clarified the difference between VDS and dedicated hardware, arguing that virtualized hardware (even VDS) shares memory bandwidth, disk I/O, and network cards, and that dedicated/bare metal is preferable. Black Swan agreed these are just provider labels.
