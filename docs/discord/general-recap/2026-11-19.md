# Community Recap — #general

**November 19, 2026** | 1:46 AM UTC – 2:51 PM UTC

## Quilscan Agent 1.2.4 Released

Quilscan released Agent 1.2.4 with a startup fix for nodes that failed to start after switching to Releases 2.1.0.25 due to a signature filename issue. The upgraded Agent automatically repairs and restarts affected nodes. Some users reported the upgrade progress window getting stuck at 0%, which Quilscan acknowledged and said they would improve the display of status and completion confirmation.

## Network Live and Stable

Multiple community members confirmed the network is live and stable following the .25 release. Black Swan noted seeing 100% certification figures, indicating nodes are getting paid for expected work. Cassie confirmed the network has been live for a while and the .25 release made participation easier.

## From Cassie

Cassie clarified the roadmap for .26 and beyond:
- **Proof compression**: As the network grows, proof contributions grow, carrying a lower bound on validation speed. .26 will include an activation epoch where proofs are recursively compressed.
- **Mac memory issues**: Macs are seeing outsized RAM usage due to memory management quirks. An M1 MBP with 64GB is fine, but an M1 Mac Mini with 16GB has issues.
- **Bandwidth optimization**: Network traffic is much higher than needed. Part of the issue is consensus using raw gossip instead of direct connections, which adds bandwidth overhead.
- **PQC status**: Quilibrium is now firmly post-quantum cryptography. The onion router is fully PQC, which Tor cannot yet claim.
- **Saturday livestream**: Will be tri-streamed on X, Twitch, and Rumble. Focus areas include the new PQ architecture, what the network enables today, roadmap, products using Q, QConsole token launch example, and Quorum/Farcaster initiatives. One partner will be explicitly mentioned.
- **Node bugs**: Dev subpatch updates will continue on the .26 branch, so fixes don't need to wait for official releases.

## Node Resource Discussion

Black Swan emphasized that archive connection and hardware matter more in this release than before. He noted quilscan-agent can consume up to 30% of internet traffic and shared a GitHub issue tracking IPv6 archive support. Felix proposed adding a health check and score to quilscan, with remediation guidance for common issues. Black Swan suggested keying off existing warn lines that map to operator fixes rather than collecting new metrics.

## Seniority Explained

Black Swan explained that seniority only matters when joining a shard—it doesn't kick anyone out. It can only take a vacant ring position in shard joining order. Vacant lower-ring positions go to the next node in shard joining order, not necessarily the highest seniority.

## Shard Growth

Black Swan noted the network is approaching over 200 app shards following recent splits. Cassie said this should increase overall earnings since shards are closer to logical shards, though frame times may increase.
