# Community Recap — #general

**November 9, 2026** | 1:23 AM UTC – 2:12 PM UTC

## Release .117 and GLOBAL Stall

Black Swan released binaries and release notes for version 2.1.0.25.117, with Cassie confirming the archives were updated. However, a significant issue emerged: the GLOBAL block store stalled at frame 1041252 around 09:05Z. Black Swan diagnosed the cause — the 512 MiB block store cap introduced in .116 was being hit on .117 because storage epoch proofs now get through the collector more efficiently, pushing frame sizes over the cap. This caused proposals to be evicted on arrival, halting finalization.

Black Swan prepared a hotfix PR that keeps new proposals regardless of the cause, and Cassie set up an alarm script to trigger bulk restarts of the archives. The archives were updated with the hotfix, and Black Swan noted the stall could recur until the fix is fully deployed.

## Wallet SDK and Addresses

rancher asked about the extremely long Quil payment addresses. Cassie explained the long addresses are needed to provide public view/spend keys, but short addresses are planned to make them easier to use. She also mentioned working on a broader wallet SDK and ORAM query support on megarpc, so quorum, quilscan, and other wallet builders have a shared implementation.

## Node Connectivity Issues

rancher reported unstable shard statuses and synchronization timeouts on a residential connection without a public IP. Black Swan suggested checking whether the node is behind CGNAT (which is hard to handle) versus a dynamic IP (which should work). Cassie noted that AutoNAT has been enhanced to support dynamic public IP changes.

## GitHub Outages

Several users reported GitHub 504 timeouts when downloading binaries. Cassie noted GitHub is under pressure and that GitLab recently had a severe RCE vulnerability, with no other SCM platforms performing better.

## Community Discussion on Self-Defense

A discussion emerged about self-defense laws, triggered by a case where a French prosecutor called a shooting revenge rather than self-defense because attackers were fleeing. Cassie expressed support for castle doctrine and noted that many countries don't permit self-defense, which she finds befuddling. Tyger argued that denying self-defense rights creates a slippery slope toward tyranny. Cassie also shared statistics comparing gun deaths to heart disease deaths. This discussion touched on themes relevant to the project's emphasis on self-sovereignty and resistance to centralized control.
