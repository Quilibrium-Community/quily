# Community Recap — #general

**November 10, 2026** | 12:30 AM UTC – 11:22 PM UTC

## From Cassie

Cassie shared a detailed progress report covering multiple fronts:

- **Quorum mobile** has a new version coming this week that completely removes React Native, eliminating the Expo dependency and making the app "insanely fast" in comparison. It ships with the new Coppice SDK (for E2EE chats in third-party clients) and the megarpc indexer, which gives integrating wallets significantly better privacy. It also adds Q mainnet support (tokens, data storage, applications).

- **Q mainnet** will see version 2.1.0.25 released soon, described as the result of an "ultramarathon of effort." It provides greater privacy for users of Quorum, VPNs built on Q, or any other integrating application.

- **Hypersnap** underwent the 0.17.4 release that begins the validator fork process — a necessary step so the upcoming POW PR only needs to concern itself with the consensus change alone.

Cassie also addressed community questions: the wallet SDK (shared by Quorum, quilscan, and other wallets) will be available for builders **this week**, and it will define a mnemonic/recovery phrase standard with Q-specific derivation for Ed448, BLS48-581, Decaf448, and confidential view/spend keys — strictly for migrating to the new Falcon and NTRU keys.

On email outreach: Cassie noted their email server has bounceback issues with Outlook/Exchange users (they use ProtonMail), and clarified they will never use Gmail due to deplatforming risks.

## Network & Development

Black Swan confirmed a node operator's report about storage epoch proof checks running on the worker's consensus thread, causing vote delays on busy disks — the check will be moved off the consensus thread.

On remaining blockers for 1.25: Black Swan and Cassie indicated no major blockers remain. Remaining work involves performance optimizations (computations, writes, proofs), security improvements (some shipped silently for obvious reasons, with notes to be published alongside regular release notes), and operational items. Black Swan is also investing in formal delivery tooling for better release velocity.

Cassie agreed to post subpatch branch update announcements to the dev updates channel going forward.

## Community Questions

A node operator raised concerns about SSD write endurance: storage-proof epochs are causing ~1.3 TB/day of writes per prover, burning through consumer QLC NVMe drives (220 TBW rated) in ~2-6 months, at a cost of ~1.3€/day per node versus a few cents in rewards. Questions about whether write volume will drop and recommended storage remain open for Cassie or Black Swan to answer.

**Resources shared:** [Coppice research repo](https://github.com/quilibriumnetwork/coppice-research) — Rust implementation available but not yet productionized for general client use.
