# Community Recap — #general

**August 28, 2026** | 12:02 AM UTC – 4:35 PM UTC

## From Cassie

Cassie provided several substantive updates today:

- **Archive Migration**: The team is decommissioning an older archive node that had been causing frame time issues. The move (via rsync) involves ~750GB of data and is nearly complete. The faulty archive was initially helpful for identifying peer catch-up issues but had become a hindrance.

- **v0.25 Update Progress**: After a successful testnet run, Cassie is creating builds for archives. The key fix addresses a prover reset issue where shard data was being put in the wrong format, causing "parent" shards that shouldn't exist. This was the root cause of missing storage root data and zero earnings.

- **Reset at Frame 754,000**: A network reset is necessary. Cassie explained the urgency vs. stability tradeoff — rushing the rollout could cause half the network to be on old builds, leading to message rejections and P2P scoring issues.

- **New Archive Online**: The replacement archive is now in place, with frames returning to ~10 seconds.

- **Subpatch Marker System**: Cassie agreed to add a `subpatch` file to the repo root to help Quilscan's automation reliably identify valid dev builds for automatic deployment.

## Network Status & Bug Fixes

- **blacks1ne** submitted a PR (#632) fixing shard info retrieval in the TUI — previously showing zero shard sizes/provers/rewards due to some archives providing empty data. Cassie merged it.

- **neon🦦** reported a node that went offline for 5 hours, then after updating and clearing the store, showed all workers at 0 rewards — likely the same archive data issue blacks1ne's fix addresses.

## Community Tools

- **Jobless** is building a native macOS menu-bar app for node management (not yet open source). **LaMat** invited him to the Quilibrium Community GitHub org for potential sharing.

- **Quilscan** confirmed their automation checks the dev branch every ~23 minutes and will add an auto-update feature for nodes (opt-in).
