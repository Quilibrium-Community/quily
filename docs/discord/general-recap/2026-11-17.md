# Community Recap — #general

**November 17, 2026** | 6:25 AM UTC – 2:44 PM UTC

## From Cassie

Cassie addressed several technical topics today:

- **MegaRPC**: Confirmed API docs and examples will be published "shortly" for developers building wallets without running full nodes.
- **Explorer halt**: Explained the recent explorer outage — a RocksDB write error (rare, random) caused one archive node to stop, and that node happened to serve the explorer API. The halt was not network-wide; the node is catching up.
- **Gold master**: Shared what appears to be the presumed gold master build, noting it depends on whether anything unexpected happens with .25.
- **FMCP++**: Clarified that the recent update tweet doesn't specify when FMCP++ will land — it links to a chat log indicating it's not ready yet and still needs an audit.
- **Archives**: Confirmed archives have been updated.
- **MEXC delisting**: Called the wQUIL delisting "unironically good news," warning that MEXC users could face frozen funds due to sanctions. Noted Binance is freezing deposits originating from MEXC, and that MEXC allegedly tells holders to withdraw within 30 days, returning funds to the original deposit address.

## Network & Node Operations

- **Shielding issues**: Aza reported a shield stuck at 42/70 batches for ~3 days. Black Swan explained that qclient .115 or earlier pauses whenever GLOBAL runs under 330 frames/h (mainnet's normal pace), while .119+ only pauses when GLOBAL stops completely. Recommended updating to the latest binaries (v2.1.0.25.121) and node build.
- **Key error**: Aza encountered "no key with id 'q-prover-key'" when shielding from an older wallet. Cassie suggested it may be a directory or config path issue, possibly a relative keys path in config.yml.
- **Frames**: aws noted frames are still progressing; only the explorer displays stopped updating.

## Community & Ecosystem

- **China network concerns**: Lukennnnnn noted Chinese nodes may face serious network issues due to strengthened firewall during the APEC meeting.
- **MEXC delisting**: Community discussed the wQUIL delisting, with mixed views — some saw it as losing a buying option, while others agreed with Cassie's assessment of MEXC's risks.
