# Community Recap — #general

**November 2, 2026** | 12:03 AM UTC – 2:08 PM UTC

## From Cassie

Cassie shared several substantive updates on Quilibrium development:

- **Enterprise interest**: Without naming companies, Cassie confirmed that "reasonably large companies" have investigated qconsole's existing offerings and see immediate value in ease of use and price. The censorship resistance and georedundancy are "icing on the cake" — multi-AZ planning being a headache for engineers that Quilibrium removes.

- **.Q domains**: When asked about browser support for .Q domains, Cassie noted Brave has had a "strange history" with integrations and dropped IPFS support. She linked to a previous message explaining an approach that works without requiring browsers to integrate native support.

- **AI tooling**: Cassie mentioned dropping her Claude subscription due to excessive safety-trigger rejections, and now uses Codex which is less verbose and doesn't refuse requests to audit her own codebase.

- **Quorum improvements**: Cassie is working on "significant changes/improvements" for Quorum, per Black Swan's update from a sync with her.

## Network Status & 10-Second Blocks

The community celebrated achieving consistent 10-second block intervals, a long-discussed objective. Black Swan credited "hard work from Cassie and the team." Tyger noted that running 2.1.0.25.X versions "feels like being part of BTC 2011" — history in the making.

## Shielding Incident & Fixes

Black Swan issued an important advisory: since ~06:00 UTC, a wave of roughly 500 batch shields stalled about a quarter of shards. Members couldn't apply frames until verifying proofs completed. The "message collector: refusing submits, rank buffer full" log message comes from this wave and isn't a node fault. Black Swan advised pausing `token shield-all` and not restarting nodes. A rerun can't charge the fee twice. Fixes are in progress.

Later, Black Swan noted the PRs addressing findings are publicly available but many remain drafts because devnet simulation runs take 5+ hours to confirm resolutions. The ❌ CI failures on GitHub are MacOS resource availability issues, safe to ignore.

## Node Migration & Key Handling

Guru_Meditation provided migration guidance: the Rust node (2.1.0.25) uses the same `.config` folder as the old Go node. Back up old keys first, as the node adds new 2.1 keys on first start. Black Swan confirmed new peer IDs are expected due to the move to post-quantum cryptography including the Falcon digital signature algorithm. Legacy coins are visible via `qclient token balance` and reported as "legacy" coins; shielding should wait until the network recovers.

## Quorum Messenger

LaMat invited community members to test Quorum Messenger, sharing an invite link to the Q community space. Some users reported issues creating accounts, with LaMat asking for specific errors and device/OS details. Black Swan explained Quorum's key generation: a 24-word BIP39 phrase from 256 bits of secure random, deriving ed448 keys via SLIP-10-style HD scheme, with the 0x address used for QNS names (can't receive QUIL today).
