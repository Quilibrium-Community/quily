# Community Recap — #general

**July 28, 2026** | 2:06 AM UTC – 9:55 PM UTC

## Daily Recap – Quilibrium Discord #general – 2026-07-28

### From Cassie
Cassie reported significant progress on the network upgrade. Archives have been updated multiple times, and the frame rate is now **steady at 10 seconds** – a milestone never achieved before. The PQC (post-quantum cryptography) upgrade made the network dramatically faster; at one point frames were running at 3s, though Cassie noted that 3s at full scale is architecturally unreasonable due to speed-of-light constraints. The dashboard UI has been updated for better visibility, though some peer info shows as zero due to type changes from the PQ migration. Cassie is resolving issues reported by node runners (simple fixes) and aims to confirm mainnet is operational before sleeping again, after which the .25 release can roll out. She also clarified that the Rust HotStuff consensus implementation was removed entirely (it was a poor port), not modified.

### Network Progress & PQC Upgrade
The steady 10s frame rate was a highlight. Cassie shared the updated dashboard: [dashboard.quilibrium.com/frames/675401](https://dashboard.quilibrium.com/frames/675401). She emphasized that 10s is the target; 3s was never intended and faces serious architectural limits (e.g., 266ms best-case RTT for cross-shard consensus). The PQ upgrade is working and is one of the "big things" mentioned earlier, though another unrelated announcement is still pending.

### Quilscan Wallet Mobile Update
Quilscan announced an Android app update with an integrated browser and wallet. iOS version is coming soon. Download link: [quilscan.com/download](https://quilscan.com/download).

### Token Discussion
A user (leoisdoingood) asked about a token equity model, deflationary mechanisms, and token utility. Cassie explained that QUIL is a utility token generated via proof of work, used for network fees and transfers. She strongly discouraged speculation, stating the project does not do buybacks, burns, or staking. The user was skeptical, but community members defended the project’s approach.

### Technical Discussion – Consensus
Otter noted modifications to HotStuff; Cassie clarified they removed it entirely. Otter suggested Commonware Simplex BFT as a better fit for QUIL’s sharded state. Cassie confirmed 10s is the goal and 3s is not viable at scale.
