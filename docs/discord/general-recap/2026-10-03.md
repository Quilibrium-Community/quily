# Community Recap — #general

**October 3, 2026** | 3:39 AM UTC – 10:34 AM UTC

## From Cassie

Cassie confirmed the `.25` branch update was released and noted that a bulk of PR merges typically signals preparation for the next branch update. She explained that when the version branch is merged into develop, it means a public release is being cut. She also addressed the previously highlighted ENOSPC (disk space) issue, stating it hasn't been root-caused yet, but other items should be resolved pending real-world confirmation. When asked about node logs, she requested them from users experiencing issues, noting that most reported problems can be addressed with the data already available.

## Node Update and Network Activity

Community members observed the `.25` update rollout, with several reporting node behavior changes. Some nodes continued running smoothly with new shards picked up, while others experienced workers going idle or leaving. Black Swan noted that all workers/allocations for the 26 shards should theoretically be active, with idle workers only expected if there are more workers than shards. They submitted a PR to enhance the leave logic, as the current implementation seems to favor more leaves than necessary. Black Swan also commented on a GitHub issue (https://github.com/QuilibriumNetwork/monorepo/issues/664) noting marginal progress but not full resolution.

## Node Diagnostics and Log Analysis

Aza shared a ChatGPT analysis of their node logs, which suggested the node was stuck in an archive-recovery/synchronisation loop rather than fully catching up. The analysis identified repeated `archive sync anchor rejected before tree writes` and `anchored global frame unavailable for ρ_N` errors, along with `anchor does not link to predecessor` messages. Cassie noted the AI analysis was missing context. Aza also reported discrepancies between Quilscan's node overview and the Manage section display, questioning whether it was a display issue. Cassie requested logs from users experiencing issues to help diagnose problems.

## Worker Status Reports

Multiple users reported varying worker statuses: MentalSharpei saw reshuffling with 18 active and 7 leaving (down from 23 active), Black Swan had 2 active and 13 leaving, and Lainexp reported 9 idle, 18 active, and 4 joining workers. The discussion centered on whether these patterns indicate remaining issues or normal network-level reshuffling during the update process.
