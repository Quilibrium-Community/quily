# Community Recap — #general

**November 5, 2026** | 12:09 AM UTC – 12:18 PM UTC

## Quilibrium Node Update 2.1.0.25.114 Rolled Out

The network rolled out subpatch .114 as a rolling update. Cassie [LEAD DEV] confirmed archive builds were still in progress, then announced the rollout starting and completing within minutes. Black Swan published unofficial node and qclient binaries for 2.1.0.25.114 on GitHub, noting they are built automatically from the release branch's bump commit until official release listings catch up. Black Swan also mentioned this was a good opportunity to polish the rolling update process for "stable" mainnet, and expects at least one more subpatch bump since some work from Cassie and Black Swan couldn't be included in .114.

## Performance Improvements Observed

Mental reported significant decreases in CPU, memory, and storage utilization after updating, asking if that was one of the objectives. Mr.Franc noted no frame slowing on the new epoch.

## qclient Signature Check Issue

Aza encountered an error when trying to shield coins from a different config: "signature check failed: quorum not met: 0 valid signatures, need at least 7 (out of 17 signatories)." Cassie explained the fix is to run with `--signature-check=false`. Black Swan noted he fixed signature validation for qclient, which had not been scanning for signatures for a while (possibly since the Rust transition). The issue arises because there are no signatures for the latest 2.1.0.25.114 binaries — signatures are only done for public releases — so users need to skip signature checks or wait for the public release. QuilScan's qclient build was also updated to .114 and requires the same flag.

## Legacy Coin Loading Issue

Hyperstax reported legacy coins failing to load in the TUI, with shielding timing out. Black Swan investigated and found the node manager gave the legacy-coin read 120 seconds total, but the listing needed about 250 seconds since each page of 512 coins is fetched from an archive. The fix keeps reading while pages arrive, shows the count as it goes, and lets users start a shield before the read finishes. Until it ships, `qclient token shield-all` shields from the shell, and `qclient token legacy --summary` lists totals.

## Clarification on wQUIL Bridge

neon asked whether the network is preparing a one-way bridge from wQUIL to QUIL. Cassie clarified this came from a joke comment taken out of context, noting people have historically taken her comments out of context for FUD purposes. Several community members confirmed they had misunderstood the joke.

## New qclient TUI Features

Black Swan asked who wanted token/coin management operations (mint, shield, merge, split, transfer) in the qclient TUI. He also noted the release includes a coin operation history feature, but since token operations are private, it relies on saving tracking data locally on the node executing the operations.
