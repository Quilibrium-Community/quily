# Community Recap — #general

**October 28, 2026** | 12:12 AM UTC – 11:14 AM UTC

## Network Progress and Fixes

The Quilibrium network experienced a significant milestone and several issues on October 28. Global frames halted when the first post-quantum coin transaction was processed, triggering a full tree rebuild that paused the network. Cassie identified the root cause: a transaction updated the QUIL token tree root, causing an unnecessary full recalculation. The fix, which bootstraps from stored per-block records instead of scanning all live vertices, has landed.

Community member Black Swan contributed several pull requests to address related issues:
- **#1013**: Verifies shield-batch proofs before taking the ingest lock, preventing archive stalls
- **#1015**: Adds a stall-watch probe for the archive's GLOBAL materializer
- **#1021**: Fixes wallet scan failures by adding a node-local index of confidential coins and escrows

Black Swan also identified a network-wide issue at the epoch 1314 boundary where 32 GB nodes failed to send renewals due to memory-queued storage snapshot jobs. The fix will confirm ready seats, run current-epoch encodes ahead of labels-ahead, and check disk before reserving memory.

## First Post-Quantum Coin Transaction

Community member Oumlaut confirmed they initiated the first coin shielding transaction, converting a legacy coin into the new privacy-preserving, post-quantum format. This is the first coin placed into the new tree, marking a major milestone for the network. Cassie noted that while many transactions have been processed, this was the first post-quantum coin transaction that created a new shard.

## Quantum Resistance Discussion

Cassie shared strong opinions on the broader crypto landscape's quantum vulnerability, stating a 90% personal probability that ECC (Elliptic Curve Cryptography) will be broken before quantum computers arrive. She noted that if ECC breaks within six months, major cryptocurrencies like Bitcoin, Ethereum, and Monero would be severely impacted. Quilibrium's advantage lies in its post-quantum cryptography, reduced code complexity from the Go-to-Rust migration, and cryptographic agility allowing component swaps.

## From Cassie

Cassie confirmed the tree rebuild finished unexpectedly before the fix was released, with frames now running. She emphasized the network still needs the branch update deployed. She also discussed the network's resilience to potential ECC breaks, noting Quilibrium could freeze its bridge and use ZKPs to help users recover assets, though EOAs without seed phrases can't create meaningful proofs.
