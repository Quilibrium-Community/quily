## .25 Branch Update Issues

TawaFiF reported two breakages on commit 86632697:

1. **Docker build failure**: The Dockerfile.sourceavx512 stage still copies Go module stubs and leaf crates that were removed or moved under `crates/` by the roll-up. The Taskfile.yaml also references Dockerfiles at the repo root when they now live under `docker/`.

2. **Rust build failure**: `crates/quil-execution/src/seniority_compat.rs` has four `include_bytes!` calls with no fallback, referencing JSON files that were deleted in the roll-up.

3. **Silent failure risk**: `crates/quil-execution/build.rs` tolerates the missing `mainnet_244200_seniority.json` by calling `emit_empty_table()`, meaning the node would compile and run with every mainnet seniority lookup returning 0 silently. TawaFiF suggested a hard failure would be safer.

Cassie acknowledged forgetting to update the Dockerfiles and worked on fixes. She later noted another update was needed to reattach a separate proof worker as part of the node process, which would cause auto quilscan builds to immediately terminate if not fixed.
