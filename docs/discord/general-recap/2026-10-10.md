# Community Recap — #general

**October 10, 2026** | 2:05 AM UTC – 11:30 AM UTC

## Node Sync Issues and "Blocked" Workers

Multiple community members reported workers stuck in "joining" or "Blocked" status with errors like "predecessor state has not been recovered through its seal" and "handoff outgoing history: required committed record absent." Steve confirmed this is a protocol/archive-side issue, not a config or hardware problem — wiping stores or restarting doesn't help. Black Swan noted that as of version 2.1, provers work in committees, so individual node configuration can't fix consensus issues. The only meaningful fix paths are regular node code changes, archive node code changes, or protocol changes.

Mr.Quil shared a detailed diagnosis of the errors, including app-shard frame gaps, missing BLS signatures, and sync issues, concluding the node itself was functional. Steve dug into the source code and confirmed the stuck workers need to pull predecessor sealed history frame-by-frame from archives, but when archives don't serve those old frames, the cursor never catches up.

Later, Mr.Quil reported seeing Blocked statuses switch to Running on their own, suggesting nodes recover with time as consensus gradually starts working.

## From Cassie

Cassie [LEAD DEV] announced that version .25 has been updated. While not all open issues are completed yet, the update should provide enough information in the logs to identify what's needed to solve the remaining open issues. This confirms the community's diagnosis that the fix is coming from the protocol side.

## Rewards and Token Economics

Mr.Franc explained that current earnings aren't representative of stable network earnings — not all shards are rewarding correctly yet, and rewards depend on which ring your worker is in (Ring 0 has the best rewards). With 7 workers in rings 0-1, they previously expected around 100 QUIL daily. VELVIL VR suggested that keeping earnings/sell pressure low at launch could help the snowball effect grow, while Mr.Franc emphasized that builders are what Quilibrium needs — they'll buy the token for apps, websites, and projects. The community noted that token price is the best marketing, though Lukennnnnn expressed caution about waiting for the bridge to open.

## TUI Development

Black Swan mentioned contributing to TUI evolution with PRs aimed at better KPI quality, and described using a coding agent to instrument their node with tooling to distinguish regular node defects from protocol or archive node topics that could be passed to Cassie with meaningful evidence.
