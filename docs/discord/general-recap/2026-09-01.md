# Community Recap — #general

**September 1, 2026** | 12:19 AM UTC – 10:18 AM UTC

## From Cassie
Cassie shared status on current fixes:
- Making splits/merges over epoch boundaries instantaneous
- Filtering app shard metadata to exclude historic and non-data shards (this will also address the "bad shards with 0 size" showing up)
- Resolving a sync report from blacks1ne; she confirmed the fix needs no reset requirement, so nodes can upgrade at any time

In response to blacks1ne's detailed report about orphan allocations and failed prover-root checks, Cassie determined his node was being served the latest root instead of the requested sync state because archives only retained 128 frames of tree state. She is boosting that to two full epochs. She also clarified that a two-epoch backfill wouldn't help recover a wiped node's proof store — the current epoch is sufficient, as proof state can't be recreated without the full join/commit loop.
