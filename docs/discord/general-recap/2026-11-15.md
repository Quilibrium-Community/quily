## Network Performance Investigation
Black Swan reported that global frames have been averaging ~16 seconds since Nov 14 (up from ~13-14 seconds, target is 10 seconds). The issue started between releases, so it's not from a new build. About 4 in 10 frames now take long to execute, and execution cost per message went up ~30% while message counts stayed flat. Black Swan is adding timing per message type to identify which message type got heavier, then will pass the numbers to Cassie for analysis.

## qclient Feature Request
TawaFiF raised a technical request: consolidating a large wallet (700 coins) is very slow because every token merge rescans the whole wallet before building its transaction, and merges take at most 4 coins. They requested a batch merge feature that scans once then builds and submits several merges (e.g., `token merge --batch` down to a target coin size). They also asked about the wallet SDK mentioned previously. Black Swan responded that they're working on the qclient batch token merge enhancement.
