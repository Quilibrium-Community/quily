# Community Recap — #general

**August 13, 2026** | 12:10 AM UTC – 6:48 AM UTC

## Node Update: v0.25 Branch
Lead developer Cassie pushed an update to the .25 branch of the Quilibrium node software. This update **does not require a store wipe**. However, Cassie warned that frame times may remain somewhat unstable while two persistently lagging archives catch up — they are recovering quickly but not instantly.

## Quilscan Fix
Quilscan announced that the Node Console seniority display issue has been fixed. Nodes with seniority will now show the correct value. Users should refresh quilscan.com to see the update.

## Seed Phrase / Account Key Export Question
User sgniwder asked if there's an update on exporting an account key for users who have a recovery phrase but want to use the web client. In response, user LaMat clarified that Quorum Desktop currently does not support importing a seed phrase — **only private key import is available**.

## Scammer Incident
A user (later confirmed as a scammer) posted in the channel and was quickly called out by multiple community members. Cassie jokingly commented on the scammer's poor choice of display name (Green Lantern). The user was likely banned.

## Bitcoin OP_IF Discussion
A user asked whether eliminating OP_IF would have stranded people's Bitcoin, calling it a terrible proposal. Cassie responded that to her knowledge, there have been no cases where this occurred on mainnet, though it was theoretically possible. She suggested it would be reasonable to extend OP_IF execution compatibility for coins minted prior to a fork.

## Summary
A relatively quiet day with a small node update, a Quilscan fix, a brief Bitcoin technical discussion, and a scammer being removed from the server.
