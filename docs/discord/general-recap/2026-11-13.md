# Community Recap — #general

**November 13, 2026** | 12:01 AM UTC – 1:23 PM UTC

## From Cassie
- Confirmed that releasing .25 remains the absolute top priority. She noted the fork is largely a configuration update, with the hard work done almost a year ago.
- Shared a reflection on building privacy and censorship-resistance tools: "you build for war in times of peace, you fight for peace in times of war." She emphasized that such tools are often undervalued until they're needed.
- Announced the .25 branch updated with subpatch .120, including consensus changes (archives must hold shard bodies before voting), fee vote enforcement scheduling, storage proof batching and deduplication, sync/disk improvements, hardening (frame-decoding memory bounds, onion dialing restrictions), and operational fixes.
- Confirmed archives were updated and dismissed a Telegram announcement about a "new $QUIL token" as absolutely fake, noting she would never use the term "blockchain" for Q.

## Node Operations & Troubleshooting
- Black Swan advised on mint timing around epoch boundaries (~01:46 UTC), noting global is busiest then. Suggested either starting early enough to finish before ~01:40 UTC or waiting until ~02:15 UTC. If a wait runs out, don't start a new mint—the error message names a `--claim` command to finish the authorized one.
- Aza shared a solution for limiting node upload bandwidth using Linux traffic control (`tc`) when the router lacks QoS/SQM capability, capping upload at 16 mbps. Black Swan confirmed this is a good fix but warned that if the cap is too tight, proofs back up at epoch boundaries—watch for `storage epoch proof still not delivered` or `submit rejected` warnings and raise the cap if seen.
- Otter reported China-based nodes failing to reach global frames after version 2.1.0.25.115, while a US VPS node worked fine. Cassie asked if there's a larger-scale routing issue in China; Otter noted many VPNs have been blocked and the government has strengthened surveillance of network anonymity protocols. Black Swan requested peer IDs and specific diagnostic commands to investigate.

## Community Tools & Scams
- Quilscan announced the Qclient Console is now available—an interactive terminal and web interface for qclient commands (balances, node status, prover operations) for Linux x86_64 and macOS Apple Silicon. Download available at quilscan.com/node-console.
- CarlXB flagged a fake community account at quilibriium.com (vs. the official quilibrium.com) with over 2,000 followers, urging reports. Cassie noted comments are intentionally closed on some channels to limit FUD, and Twitter doesn't fix report-bombed accounts quickly.
