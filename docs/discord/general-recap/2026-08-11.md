# Community Recap — #general

**August 11, 2026** | 12:23 AM UTC – 7:55 AM UTC

## From Cassie

Cassie resolved two issues overnight: a cache problem with explorer data (she had set cache times to 7 days, causing stale frames to appear after rewinding the head) and a Falcon bug where the mTLS client was incorrectly preferring the Ed448 key. Both fixes are included in the `.25` update, which she pushed and later updated with additional client fixes.

On the codebase, Cassie noted that the Rust conversion dramatically reduced the code size from roughly 8 million lines (in Go) to around 400k lines, with some vendor-patching. She also confirmed that `qclient` is being wrapped up.

When asked about AI tooling, Cassie said she uses Claude Code where useful — for building test cases, setting up environments, and handling some bug cases. She noted that reliability improved significantly around Claude 4.5, and that versions 4.8 and 5 can now build entire features for well-defined problems.

## Network Progress

Mr.Franc reported seeing 391 active workers and shard split requests, with one shard at 32 active workers doing re-bundling (split into two shards of 16). He noted the network had never reached this stage before and asked whether successful re-bundling would mean readiness for official release. Cassie responded "in theory yeah" regarding the release, and that qclient is being finalized.

## Development Updates

The `.25` update was released with both the cache/Falcon fixes and client fixes. Community members expressed optimism about the progress, with several noting the network appears healthy and frames are advancing quickly.
