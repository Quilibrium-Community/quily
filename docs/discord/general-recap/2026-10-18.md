## Version Update Issues
Aza discovered they were running qclient 2.1.0-p22 while Quilscan showed version 2.1.0.29. When attempting to update, they encountered a permission denied error. Black Swan uploaded v2.1.0.25-tip of `qclient-linux-amd64` to a Google Drive folder. Aza successfully installed it after following the instructions.

Black Swan noted that the version Aza was running was quite outdated, missing many enhancements. They also mentioned that logging now exists to tell users what to report and what self-resolves, plus a log exporter with private data anonymization. Black Swan said they'd write a post about the logging changes later.

Quilscan clarified that their qclient stays in sync with the latest 2.1.0.25 branch, and the .29 version number is used so the Agent can correctly detect and apply updates. They plan to change the displayed version to 2.1.0.25.xx for clarity.

## App Shards Progress
Finn asked how many app shards are needed for a "hinge" to be complete and what's stopping progress. Each PR fixed another revealed weakness, so the project quality impact is positive. There are approximately 97 app shards at the moment.
