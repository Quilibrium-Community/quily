# Quilibrium Discord Recap — 2026-08-31

## From Cassie

Cassie reported working on two issues: sync discrepancies flagged by blackswan and a shard size problem. She confirmed that the fix for these will not require bumping the version to .26 — the current branch will resolve it without a reset. Archives have already been restarted to address the shard size issue, though the sync discrepancy is "somewhat weird."

She also noted that the shard out worked, but the size data used to take actions was not updating with the shard out — a simple fix. Cassie clarified that updates will always happen, but the current state is much better than prior .25 updates.

Regarding the shard endpoint, she explained it exposes membership of inactive shards (likely used by quilscan), but the actual active shards are all healthy. Peers on old .25 versions may have joined those inactive shards.

Cassie asked Danske to send his config (without peerPrivKey and encryption key) to debug worker connection failures, and suggested checking if master and worker logs show different `prover_address` values.

## Network Status & Development Progress

Cassie stated the network is "pretty damn close" to official release. She wants to see stability over the next few epochs and earnings accruing on mainnet — that would greenlight the release. Mr.Franc noted the network is healthy if excluding the inactive shards, and Cassie agreed those shards are "not real" anymore.

Mr.Franc also observed that non-blue shards correspond to nodes on older .25 versions.
