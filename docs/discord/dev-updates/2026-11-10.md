# dev-updates - November 10, 2026

## Cassie — 12:16 PM UTC

re-sharing from other comms channels as others felt it would be good to go in an announcements-only channel:

Wanted to give a brief progress report of all that is ongoing so folks know what's in flight on my end.

Quorum mobile has a new version coming this week. It completely removes react native, which means we no longer will have a dependency on expo, and the app will be insanely fast in comparison. It will be released with the new coppice SDK, so other builders can use it for E2EE chats in their own clients, and the megarpc indexer, which allows wallets that integrate it to have significantly better privacy than regular wallets. It also will introduce support for Q mainnet, which has been running smoothly for a while now, with support for tokens, data storage, applications, and more.

Q mainnet itself is going to see 2.1.0.25 released very soon, it's been undergoing an absolute ultramarathon of effort, and it will pay off immensely, by providing a means to greater privacy of users, whether on Quorum, or a VPN built on Q, or any other application that integrates it.

Finally, hypersnap as folks have already seen, has undergone the 0.17.4 release update that begins the validator fork process. This is a necessary step to ensure the features we are adding work ahead of the POW PR, so the only thing the POW PR need be concerned with is the consensus change alone.

I want to extend my personal thanks across the Q, FC, and Ethereum ecosystems for all the incredible work, communication, development, and energy that has been gravitating around all of this. This week is looking to be one of the biggest in both desoc and depin in quite some time, but most won't know it until it is determined in retrospect. I appreciate you all.
